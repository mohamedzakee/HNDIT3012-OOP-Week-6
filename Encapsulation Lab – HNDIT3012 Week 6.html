What is encapsulation?

Bundling data (variables) with the methods that operate on that data into a single unit, the class. Other classes can't touch the data directly; only the class's own methods can.

Data (private)

private String name; private int age;

Methods (public)

getName() setName(n) setAge(a)
👆 Click any part of the capsule to see what it does.

The two rules

① Make fields private

private String name;

② Provide public get / set methods

public String getName() { return name; }
public void setName(String newName) {
    this.name = newName;
}

Real-world analogies

💊
Capsule

The medicine (data) is sealed in a shell. You take the whole capsule, never the powder.

🏧
ATM

You can't open the cash box. You use the interface (PIN, amount) and the machine checks every request.

🚗
Car

You control speed with pedals, not by reaching into the engine. The pedals are the public methods.

Advantages (exam favourite)

🎛️
Better control

The class decides who can read or change its attributes, and how.

👁️
Read-only / write-only

Getter only = read-only. Setter only = write-only.

🔧
Flexible

Change one part of the code (the inside of the class) without affecting other parts.

🛡️
Security of data

Sensitive data is hidden and protected by validation.

🐞
Easier debugging

Only one place (the setter) can change a field, so bad values are easy to trace.

♻️
Reusable & testable

A self-contained class is easy to reuse and test.
